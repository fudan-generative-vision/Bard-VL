# Preprocessing Guide

This directory contains the dataset conversion utilities used to build Bard-VL training data from public Hugging Face datasets.

## What This Pipeline Does

`tools/preprocessing.sh` performs up to four stages:

1. Downloads the source datasets:
   - `mvp-lab/LLaVA-OneVision-1.5-Instruct-Data`
   - `HuggingFaceM4/FineVision`
   - `OpenDataArena/MMFineReason-1.8M-Qwen3-VL-235B-Thinking`
2. Runs the local conversion scripts:
   - [`convert_finevision.py`](./convert_finevision.py)
   - [`convert_llava_onevision.py`](./convert_llava_onevision.py)
   - [`convert_mmfine.py`](./convert_mmfine.py)
3. Downloads the mixed metadata set:
   - `fudan-generative-ai/mixed-8192-17M`
4. Optionally downloads the distillation dataset used by the KD configs:
   - `fudan-generative-ai/mixed-distil-17w`

All paths are resolved relative to the repository root and written under `datasets/`.

## Prerequisites

Install the repository dependencies first:

```bash
pip install -r requirements.txt
```

Minimum Python packages required by this pipeline:

- `huggingface_hub`
- `datasets`
- `Pillow`
- `tqdm`

If you need authenticated access or a higher rate limit, export a Hugging Face token before running:

```bash
export HF_TOKEN=hf_xxx
```

## Quick Start

Run the full pipeline:

```bash
bash tools/preprocessing.sh
```

Run it in the background and write logs to the default log file under `logs/`:

```bash
bash tools/preprocessing.sh --background
```

Run it in the background and write logs to a custom file:

```bash
bash tools/preprocessing.sh --background --log-file logs/preprocessing.log
tail -f logs/preprocessing.log
```

Relative log paths passed with `--log-file` are resolved against the repository root.

Run only a single stage:

```bash
bash tools/preprocessing.sh --download-only
bash tools/preprocessing.sh --convert-only
bash tools/preprocessing.sh --metadata-only
bash tools/preprocessing.sh --distill-only
```

Download the distillation dataset in addition to the normal preprocessing outputs:

```bash
bash tools/preprocessing.sh --distill-data
```

If you only need the KD dataset and prefer the Hugging Face CLI, run this from the repository root:

```bash
huggingface download fudan-generative-ai/mixed-distil-17w --local-dir datasets/mixed-distil-17w
```

Preview the commands without executing them:

```bash
bash tools/preprocessing.sh --dry-run
```

Use a non-default Python binary:

```bash
PYTHON_BIN=python bash tools/preprocessing.sh
```

## Expected Output Layout

After a successful run, the repository `datasets/` directory will contain the downloaded raw datasets and the processed outputs generated by the conversion scripts.

Typical output structure:

```text
datasets/
├── FineVision/
├── FineVision-processed/
├── LLaVA-OneVision-1.5-Instruct-Data/
├── LLaVA-OneVision/
├── MMFineReason-1.8M/
├── MMFineReason-Processed/
├── mixed-8192-17M/
└── mixed-distil-17w/
```

The processed directories usually contain:

- extracted JPEG images under `images/`
- `llava.json` and/or `qwen3.json` conversation files

## Resume and Re-run

- Dataset downloads are performed via `huggingface_hub.snapshot_download`, which supports resume behavior.
- Re-running `bash tools/preprocessing.sh` is generally safe.
- Some converters may skip already converted outputs based on the files they check internally.

If you want to re-convert from scratch, remove the corresponding processed directory first, for example:

```bash
rm -rf datasets/FineVision-processed
```

## Troubleshooting

If download fails:

- verify network access to Hugging Face
- set `HF_TOKEN` if the environment needs authenticated access
- confirm Python can import `huggingface_hub`
- for KD training configs, confirm `datasets/mixed-distil-17w` exists locally

If conversion fails immediately:

- verify you installed `requirements.txt`
- verify the raw datasets exist under `datasets/`
- run `bash tools/preprocessing.sh --convert-only` after fixing the missing dependency

If a converter is too slow or uses too much CPU:

- reduce `NUM_WORKERS` inside the target conversion script
- narrow `SUBSETS` before running large conversions
